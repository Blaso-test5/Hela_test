Controlled Hela run
-------------------
Use the diagnostic d3d12.dll in the Hela binary directory and keep the
matching d3d12.pdb available for offline analysis with WinDbg. Set this
environment variable before starting the game:

  D3D12ON11_CRASH_DIAGNOSTICS=1

The handler defaults to off. It writes the report and dump beside d3d12.dll
when the module location is resolvable, otherwise it uses the process temp
directory. A first-chance report may correspond to a handled exception;
compare its timestamp and thread/address with the process exit, UE log, and
Windows crash details before treating it as the fatal fault. Preserve the
matching PDB when opening the dump to resolve proxy module offsets.
