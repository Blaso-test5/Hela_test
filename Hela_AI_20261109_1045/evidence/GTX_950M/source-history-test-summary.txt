Interpretation and limits
The test confirms that the specified source resources had RTV-bound draw
commands executed with the listed shaders and viewport; those draw calls
were not skipped, and no RTV clears were recorded for these resources.
This run did not read back the source or backbuffer pixels. The black
window alone does not establish that these particular draws produced black
pixels, nor does the bounded history establish every operation during the
full run. A pixel readback must be enabled in the same shader-override run
to determine the source contents after these draws.
